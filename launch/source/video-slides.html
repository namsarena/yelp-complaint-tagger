How it could improve

Five upgrades for version 2.

01

A bigger human-checked test set

Score against people, not only the AI labeller

02

Add happy and neutral reviews

So it can say “no complaint”

03

More rare examples

Billing and wrong orders need more data

04

Show the evidence

Highlight the sentence behind each tag

05

A weekly dashboard

Run it on every new review automatically

Known limits today: complaints only (not 5-star reviews), trips on negation, and copies some habits of its AI labeller.

Where this helps

Six practical use cases.

Owners and managers

Weekly complaint breakdown: fix the right thing first

Groups and franchises

Compare locations; send help where wait times spike

Delivery platforms

Route each complaint to the right team

Reputation agencies

Hundreds of reviews into a one-page monthly report

Restaurant software

Review insights inside POS or reservation tools

Food-safety teams

Surface hygiene complaints fast for follow-up

Beyond restaurants: hotels, clinics, retail, winery tasting rooms. Change the labels, get a new model.
